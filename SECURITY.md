# Security policy

Please do not open a public issue for a security problem.

Report it through GitHub's **private vulnerability reporting** on this repository (Security tab, "Report a vulnerability"). Include the plugin version, what you did and what happened. We will confirm receipt, work on a fix and credit you in the changelog if you want.

Only the latest released version is supported. See [docs/security.md](docs/security.md) for how the plugin protects data.
